# 뭐샀지

고양이·강아지 용품, 옷, 일상 구매를 한 줄로 기록하고 월별 소비와 재구매 시점을 확인하는 한국어 반응형 웹 앱입니다. 모바일 브라우저와 데스크톱에서 사용하며 홈 화면에 설치할 수 있습니다.

## 실행

이 폴더에서 `npm start`로 정적 미리보기 서버를 실행하고 터미널에 표시된 주소를 여세요. `npm test`로 구매 해석과 알림 계산 등 핵심 로직을 검증합니다. 빌드 결과물은 `dist/`에 있으므로 해당 폴더를 정적 웹 서버로 제공해도 됩니다. 별도 API 키나 서버 데이터베이스는 필요하지 않습니다.

## 데이터와 알림

- 구매 기록은 현재 기기·브라우저의 로컬 저장소에 보관합니다. 다른 기기와 자동으로 동기화되지 않으며 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 예시 데이터는 기능을 둘러보기 위한 데모입니다. 직접 입력한 구매 기록과 실제 잔량을 의미하지 않습니다.
- 소모품의 예상 주기와 사용자의 응답을 기준으로 앱 안에서 재구매 안내를 표시합니다. 실제 재고를 측정하거나 앱이 닫혀 있을 때 백그라운드 푸시를 보내지는 않습니다.
- 자연어 입력은 앱 안의 규칙 기반 해석을 사용합니다. 클라우드 AI 서비스에 구매 메모를 전송하지 않습니다.

## 모바일 설치와 오프라인

배포된 HTTPS 주소로 앱을 한 번 열면 앱 파일을 캐시해 오프라인에서도 열 수 있습니다. Android의 지원 브라우저에서는 설치 메뉴를, iPhone에서는 Safari의 공유 → 홈 화면에 추가를 이용하세요. 브라우저에 따라 설치 방식이 다릅니다. 모바일 실기기에서는 배포된 HTTPS 주소를 사용하세요.

`localhost`, `127.0.0.1`, `::1`의 로컬 미리보기에서는 수정한 파일이 즉시 반영되도록 서비스 워커 캐시를 사용하지 않습니다. 이전 로컬 앱 캐시도 새 서비스 워커 활성화 시 정리합니다. 오프라인 기능은 배포된 HTTPS 주소에서 확인하세요.

서비스 워커는 같은 출처의 지정된 앱 파일만 캐시합니다. 외부 출처, API·인증 경로, 쿼리가 있는 요청은 캐시하지 않습니다. 앱을 배포해 변경할 때는 `dist/sw.js`의 캐시 버전도 올려 주세요.
