# 뭐샀지

고양이·강아지 용품, 옷, 일상 구매를 한 줄로 기록하고 월별 소비와 재구매 시점을 확인하는 한국어 반응형 웹 앱입니다. 모바일 브라우저와 데스크톱에서 사용하며 홈 화면에 설치할 수 있습니다.

## 실행

이 폴더에서 `npm start`로 정적 미리보기 서버를 실행하고 터미널에 표시된 주소를 여세요. `npm test`로 구매 해석과 알림 계산 등 핵심 로직을 검증합니다. 빌드 결과물은 `dist/`에 있으므로 해당 폴더를 정적 웹 서버로 제공해도 됩니다. 별도 API 키나 서버 데이터베이스는 필요하지 않습니다.

## 내 기기에만 보관하는 개인 가계부

- 구매 기록과 가계부 설정은 현재 휴대폰·PC의 브라우저 저장소에 암호화해 보관합니다. 앱 서버, 클라우드 데이터베이스, 분석·광고 서비스로 기록을 전송하지 않습니다. 웹 호스팅 로그인은 앱 잠금 암호와 별개입니다.
- 처음 사용할 때 앱 잠금 암호를 정합니다. Web Crypto의 PBKDF2로 암호화 키를 만들고 AES-GCM으로 데이터를 암호화합니다. 앱 잠금 암호는 서버에 보관하지 않으며 클라우드 암호 복구 기능도 없습니다. 암호를 잊으면 암호화한 기록과 백업을 열 수 없으므로 반드시 기억해 주세요.
- 기존 버전의 평문 기록이 있는 경우, 암호를 설정하고 암호화한 기록의 저장이 성공한 뒤 기존 평문 기록을 제거합니다.
- 휴대폰과 PC, 서로 다른 브라우저, 로컬 미리보기 주소와 배포 주소의 기록은 각각 별개입니다. 자동 동기화나 타인과의 공유 기능은 없습니다. 기기를 옮길 때는 사용자가 직접 암호화된 백업 파일을 내보내고 다른 기기에서 가져옵니다.
- 브라우저 데이터를 지우거나 브라우저가 저장소를 정리하면 기록도 삭제될 수 있습니다. 필요한 기록은 암호화된 파일로 백업해 주세요. 백업 파일 위치와 운영체제·브라우저의 백업 또는 동기화 설정은 사용자가 관리합니다. 앱이 이를 끄거나 보장하지는 않습니다.
- 암호화는 잠긴 저장 기록과 백업을 보호하기 위한 기능입니다. 앱이 잠금 해제된 기기를 다른 사람이 사용하거나 앱 출처의 스크립트가 변조된 경우까지 보호하지는 못합니다.
- 구매 입력은 기기 안의 규칙 기반 해석을 사용하며, 구매 메모나 영수증을 클라우드 AI에 전송하지 않습니다. 네트워크는 같은 출처의 앱 파일 로딩과 호스팅 로그인에 사용됩니다.

## 알림과 예시

- 예시 데이터는 기능을 둘러보기 위한 데모입니다. 직접 입력한 구매 기록과 실제 잔량을 의미하지 않습니다.
- 소모품의 예상 주기와 사용자의 응답을 기준으로 앱 안에서 재구매 안내를 표시합니다. 실제 재고를 측정하거나 앱이 닫혀 있을 때 백그라운드 푸시를 보내지는 않습니다.
- 캘린더 파일은 상품명·금액 없이 일반적인 재구매 안내로 내보냅니다. 사용자가 해당 파일을 캘린더에 등록하면 캘린더의 저장·동기화 설정이 적용됩니다.

## 모바일 설치와 오프라인

배포된 HTTPS 주소로 앱을 한 번 열면 앱 파일을 캐시해 오프라인에서도 열 수 있습니다. Android의 지원 브라우저에서는 설치 메뉴를, iPhone에서는 Safari의 공유 → 홈 화면에 추가를 이용하세요. 브라우저에 따라 설치 방식이 다릅니다. 모바일 실기기에서는 배포된 HTTPS 주소를 사용하세요.

`localhost`, `127.0.0.1`, `::1`의 로컬 미리보기에서는 수정한 파일이 즉시 반영되도록 서비스 워커 캐시를 사용하지 않습니다. 이전 로컬 앱 캐시도 새 서비스 워커 활성화 시 정리합니다. 오프라인 기능은 배포된 HTTPS 주소에서 확인하세요.

서비스 워커는 같은 출처의 지정된 앱 파일만 캐시하며 구매 데이터는 캐시에 넣지 않습니다. 외부 출처, API·인증 경로, 쿼리가 있는 요청은 캐시하지 않습니다. 업데이트는 필수 앱 파일을 모두 확보한 뒤 적용합니다. 필수 파일을 가져오거나 저장하는 데 실패하면 이전 오프라인 버전을 유지하고, 선택적인 아이콘 파일의 실패만 허용합니다. 앱을 배포해 변경할 때는 `dist/sw.js`의 캐시 버전도 올려 주세요.
